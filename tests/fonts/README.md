# Test fonts

`DejaVuSans.ttf` (DejaVu Sans 2.37, the same file as the pinned build image's
`fonts-dejavu-core` package) stands in for the 3DS system font in host text-width
checks, so every machine measures the same glyphs. License: `LICENSE-DejaVu.txt`
(Bitstream Vera and Arev font licenses, free to redistribute). It is a test input
only; it is not shipped in the app.
